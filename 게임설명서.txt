붕어빵 장인 — 게임 설명서 / 실행 안내

1. 실행
ZIP을 모두 압축 해제한 뒤 bungeoppang-tycoon.exe를 실행하세요.
bungeoppang-tycoon.pck를 EXE와 같은 폴더에 두어야 합니다.
Windows x86_64 / 960×540 / 인터넷 연결 없이 플레이합니다.

2. 게임 시작 및 조작
일반 또는 이지 난이도를 선택하고 게임 시작을 누릅니다. 시작 전 닉네임은 필요 없습니다.
3·2·1 준비 후 90초 동안 판매 금액에 도전합니다.
주전자→틀(첫 반죽), 주걱→틀(팥), 주전자→틀(두 번째 반죽) 순서로 넣습니다.
첫 반죽부터 시간이 흐릅니다. 첫 면이 익으면 틀을 클릭해 뒤집고,
두 번째 면이 익으면 클릭해 봉투에 담습니다. 도구를 들고 있어도 뒤집기·수거가 됩니다.
재료 투입에 성공하면 도구가 해제됩니다. 도구 재클릭 또는 우클릭으로도 해제합니다.
봉투에 3개가 모이면 판매 영역으로 드래그합니다. 영역 밖 드롭·Esc·우클릭은 취소입니다.
봉투가 가득 차면 더 수거할 수 없습니다. 시간 종료 시 미판매 봉투와 틀의 빵은 사라집니다.

3. 조리 시간 (일반 → 완벽 → 탐)
일반 첫 면: 5~7초 일반 / 7초 초과~9초 완벽 / 9초 초과 탐
일반 두 번째 면: 3~4.5초 일반 / 4.5초 초과~6초 완벽 / 6초 초과 탐
이지 첫 면: 5~8초 일반 / 8초 초과~12초 완벽 / 12초 초과 탐
이지 두 번째 면: 3~5초 일반 / 5초 초과~8초 완벽 / 8초 초과 탐
양면 모두 완벽하면 맛있는 붕어빵, 한 면이라도 일반이면 일반 붕어빵입니다.
수거 전까지 계속 조리됩니다. 탄 붕어빵도 수거할 수 있습니다.
3개 모두 맛있는 봉투는 2,000원, 모두 일반이면 1,000원, 모두 타면 0원입니다.

4. 결과 및 기록 저장
종료 후 최종 판매 금액과 해당 난이도 TOP 10을 확인합니다. 자동 저장되지 않습니다.
결과 화면에서 입력·변경 → 닉네임 입력 → OK → 적용 → 기록 저장 순서로 등록합니다.
닉네임은 앞뒤 공백을 제외한 1~12자이며 빈 값은 저장할 수 없습니다.
입력을 취소하려면 네이티브 입력창의 OK 후 다음 확인창에서 취소를 누릅니다.
기록 저장 완료 표시를 확인하세요. 성공 후에는 같은 판을 다시 저장할 수 없습니다.
저장 실패 시 결과와 이름이 유지되며 기록 저장을 다시 누를 수 있습니다.
저장하지 않고 다시 하기·시작 화면으로 이동하면 해당 판의 기록은 남지 않습니다.
새 판은 닉네임·저장 상태를 초기화합니다. 다시 하기는 같은 난이도를 유지합니다.

5. 랭킹 및 데이터
일반·이지 TOP 10은 별도입니다. 시작 화면에서 난이도를 바꿔 조회합니다.
동일 닉네임의 여러 판과 0원도 별도 기록이며 금액순, 동점은 먼저 달성한 기록순입니다.
게임을 완전히 종료하고 재실행해도 저장된 기록은 유지됩니다.
저장 위치: %APPDATA%\Godot\app_userdata\붕어빵 장인\
일반: rankings.json / 이지: rankings_easy.json
